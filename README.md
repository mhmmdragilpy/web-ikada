# 🎬 IKADA — Project Konten Tongkrongan

> **“Dari tongkrongan, jadi cerita. Dari cerita, jadi konten. Dari konten, jadi karya.”**

Repositori ini memuat dokumentasi resmi serta portal web informasi untuk **Project Konten IKADA**, inisiatif kreatif berbasis tongkrongan yang mengangkat keseharian, olahraga, humor, masyarakat, dan kebersamaan menjadi konten bermakna.

## ⚡ Skills Terpasang (Anti-AI Slop & Creative Craft)
- `.agents/skills/frontend-design`: Standar desain deliberately non-templated, tipografi berkarakter, dan penataan visual kontekstual.
- `.agents/skills/anti-ai-slop`: Guardrail pencegahan klise AI (banned generic purple gradients, banned robotic SaaS copy, banned sterile bento grids).
- `.agents/skills/tongkrongan-creative-ui`: Panduan visual culture anak muda, indie production studio, camcorder elements, dan high-contrast streetwear aesthetic.
